## 行为

- HTML 直接呈现加载层，背景从首帧跟随 `prefers-color-scheme`。
- v13 播放器保留 v12 的形成、展示、沿线退出；等待期间循环。
- 等待当前 `<picture>` 选中的图片加载、解码，以及影片 `canplay`。
  不等待循环视频整段下载，减少无意义的白屏等待。
- 至少完成正常动画一整轮（5.4 秒）后，等待影片在遮罩下输出首个有效画面、播放控制完成布局，再开始退场。保留默认静音、返回影片及减少动态效果行为。
- 两项条件全部满足后调用品牌 v13 的 `finish({ surface: overlay })`，整个品牌加载层在 640ms 内逐渐高斯模糊至 14px，并同时淡出。滤镜只作用于品牌层，影片不增加模糊。淡出期间影片持续播放，React 状态交接不暂停或重启影片。
- 6 秒更新等待说明；15 秒提供重新加载按钮，继续等待资源。图片、影片或播放失败时保留品牌遮罩并提示重试，不自动露出尚未准备好的影片。
- 加载期间主页不可聚焦，影片切换手势也不会穿透遮罩。
- 系统减少动态效果时呈现静态标志，资源与按钮就绪后展示封面及手动播放按钮，不自动播放。
- 深浅色延伸至首页、项目正文、技术能力、个人介绍及弹窗。插画维持原始设计配色。

## 验证

- `npm run build`：类型检查、生产构建、原始影片校验和 10 项部署资源校验。
- `npm test`：63 项通过，包含 13 项品牌入口的完整首轮、真实视频帧、播放失败、等待控制与资源就绪检查。
- 实际浏览器：系统深色偏好、390 × 844 手机布局、影片入口、默认静音。
- 实际浏览器确认：缓存图片全部加载、视频 readyState=4 时，品牌仍处于第一轮 logo 展示阶段，影片保持暂停；退出后视频持续播放，三个按钮均可见且可操作。
- 浅色视觉使用临时本地代理反转颜色媒体查询验证，未修改操作系统外观设置；手机无横向溢出。

本次提交同时保留并纳入此前已有的细节润色、锚点导航、阅读位置恢复与响应式适配。远程推送不等于服务器部署完成。
