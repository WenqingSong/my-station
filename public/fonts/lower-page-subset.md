# Lower-page Chinese subset

`lower-page-sc.woff2` is a 372-character subset of Noto Sans SC, using the same OFL license included as `NotoSansSC-OFL.txt`. It covers the non-ASCII characters in SelectedWork, work-evidence, AboutEditorial and Contact at the October 15, 2026 revision. Size: 96,548 bytes. It is scoped to these sections; it does not change Hero or Opening fonts.

Produced with FontTools `fontTools.subset`, WOFF2 output, all layout features retained, from the Noto Sans SC variable TTF used in the earlier font comparison. On copy changes, regenerate the union of non-ASCII codepoints in those four source files. Do not overwrite the separate Hero/Opening font assets. System CJK fonts remain a fallback if the subset is unavailable.
