# 思想图片占位回归

2026-11-04，本地生产构建。

用户公网截图显示人物区域空白。源码存在两个独立 Image 对象：预加载对象与页面显示对象。旧实现用前者的 Promise 撤掉后者的品牌占位，不能保证实际图片已经加载、解码。

本次调整：

- 只由实际显示的 img 的 load / error / decode 结果控制占位。
- 每次图片源切换重置状态；卸载后忽略旧解码结果。
- 保留提前预加载，但不把它作为显示完成的证明。
- 品牌占位从可辨认形态开始，循环间隙保留品牌字标。移除整个 figure 的入场透明动画，避免占位被一起隐藏。

验证：

- 测试服务器将 Robert 图片响应延迟 60 秒。浏览器记录 complete=false、naturalWidth=0、data-media-ready=false，品牌占位数量为 1；截图 outputs/image-loader-slow.png。
- 响应完成后 complete=true、naturalWidth=960、data-media-ready=true，品牌占位数量为 0。
- 正常生产预览中 Robert → OpenAI → Robert 连续切换，两张图正常显示；控制台无错误或警告。
- 76/76 自动检查通过；生产构建通过。

验证覆盖慢下载、延迟解码、已缓存图片、卸载后回调与加载错误。未在用户截图对应的设备上复现其确切触发条件；不能据本地结果断言公网已更新。
